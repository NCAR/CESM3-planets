# Welcome to CESM3-Planets

**CESM3-Planets** is an advanced adaptation of the Community Earth System Model (CESM3) designed to simulate the atmospheric and surface environments of terrestrial exoplanets, with an initial focus on **Mars**.

This project builds upon the legacy of CESM-Planets but fully integrates with the modern CESM3 framework, utilizing the NUOPC driver, the Spectral Element dynamical core (SE), and the Community Land Model (CTSM/CLM5).

For Specific information on this project please refer to the Wiki https://github.com/NCAR/CESM3-planets/wiki

As this is a fork of CESM it adds exo-planet simulation capability to the CIME infrastructure as well as the atmosphere (CAM) and land (CTSM)  and coupler/mediator components.  

For more information on the CESM framework that underlies CESM3-planets please see the CESM web site for documentation and information:

http://www.cesm.ucar.edu
